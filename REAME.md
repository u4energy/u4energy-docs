# U4 Energy Documentation

## Pengenalan

Repository ini merupakan pusat dokumentasi rasmi U4 Energy yang menyimpan semua maklumat berkaitan hala tuju syarikat, strategi perniagaan, model pendapatan, kajian pasaran, operasi syarikat, pengurusan rakan strategik dan portfolio produk.

Tujuan utama repository ini adalah untuk memastikan semua pengetahuan dan keputusan strategik syarikat direkodkan secara sistematik, mudah dicapai dan boleh dijadikan rujukan oleh pengurusan, pelabur, rakan strategik serta ahli pasukan pada masa hadapan.

Repository ini tidak menyimpan dokumentasi teknikal produk. Dokumentasi produk disimpan secara berasingan di dalam repository masing-masing seperti `wattsense-docs`.

---

## 01-vision-mission

Folder ini mengandungi asas penubuhan dan hala tuju syarikat.

Dokumen dalam folder ini menerangkan:

* Visi syarikat
* Misi syarikat
* Nilai teras organisasi
* Matlamat jangka panjang
* Prinsip operasi syarikat

Folder ini menjadi rujukan utama bagi memastikan semua keputusan strategik selari dengan objektif asal U4 Energy.

---

## 02-strategy

Folder ini mengandungi perancangan strategik syarikat bagi tempoh jangka pendek, sederhana dan panjang.

Dokumen dalam folder ini boleh merangkumi:

* Roadmap syarikat
* Pelan pertumbuhan perniagaan
* Strategi kemasukan pasaran
* Strategi pembangunan produk
* Strategi pengembangan serantau
* Strategi kerjasama strategik

Folder ini menjawab persoalan:

> Ke manakah hala tuju U4 Energy dalam tempoh 1, 3 dan 5 tahun akan datang?

# Hubungan Dengan Repository Lain

Repository ini memberi fokus kepada dokumentasi peringkat syarikat.

* wattsense-docs
* futurecarbon-docs

Kod sumber aplikasi dan infrastruktur pula disimpan dalam repository teknikal yang berasingan.

---

# Objektif Repository

Repository ini diwujudkan bagi memastikan:

* Pengetahuan syarikat direkodkan secara sistematik
* Keputusan strategik mempunyai sejarah dan rujukan yang jelas
* Perancangan syarikat dapat diwariskan kepada pasukan pada masa hadapan
* Maklumat penting tidak bergantung kepada individu tertentu
* Semua pihak berkepentingan mempunyai sumber rujukan yang sama dan konsisten
